# 한 곳만 남긴다면

제주의 옛 클린하우스 한 곳을 다시 이용한다고 가정하고, 어느 공동주택의 종량제 배출길이 얼마나 짧아지는지 비교하는 센터 PC용 서비스입니다. 유수암리·금능리·봉성리를 지원합니다.

[설치 없이 공개 데모 열기](https://hakm12-ship-it.github.io/jeju-one-place/)
 
금능리의 등록 공동주택 71세대는 한림로 180 도움센터를 이용할 수 있다고 가정하면 옛 후보 네 곳 중 어디를 추가해도 배출길이 더 짧아지지 않습니다. 도움센터를 제외할 때, 또는 유수암리에서 광상로 344에 자체 수거함이 있다고 볼 때 순위가 어떻게 달라지는지 데모에서 확인할 수 있습니다. 운영 여부는 현장 확인 사항입니다.

웹에서 세 마을, 도움센터, 자체 수거함, 네 거리 문턱 및 두 순위 기준을 바꿔 볼 수 있습니다. 공개 데모의 384가지 결과는 `python scripts/build_demo.py`로 센터 실행판과 같은 계산 도구에서 다시 생성할 수 있습니다. Claude 자유 질문과 직접 측정한 거리 입력은 아래 센터 실행판에서 이용합니다.

## 실행

1. ZIP의 **압축을 모두 풉니다**. Windows에서 Python 3.10 이상과 Edge 또는 Chrome을 준비합니다. Python용 추가 패키지는 없습니다.
2. 폴더의 **start.cmd**를 두 번 클릭합니다. 기본 브라우저에서 마을 비교 화면이 열립니다. 창이 열리지 않으면 콘솔에 나온 127.0.0.1 주소를 브라우저에 입력합니다.
3. 사용을 마치면 콘솔에서 Ctrl+C를 누릅니다. 화면의 조건은 새로 고침하면 초기화됩니다. 다른 사람의 입력 이력을 저장하지 않습니다.

터미널에서도 `py -3 -X utf8 app.py` 또는 `python -X utf8 app.py`로 실행할 수 있습니다. 지정한 포트에서 브라우저를 자동으로 열지 않으려면 `python app.py --port 8765 --no-browser`를 사용하세요. 개발 검증 환경은 Windows · Python 3.12 · Edge입니다. 센터 실기기 검증은 남아 있습니다.

## 1분 사용 예

1. **유수암리** 기본 화면은 마을 도움센터에서 종량제봉투를 받을 때의 결과입니다. 혜택 세대 수 기준으로 보건소 맞은편·경로당옆·광상로 310 동측도로가 각 28세대로 공동 1위입니다. ‘도움센터 이용 여부에 따른 1위’에서 제외 시 결과인 거문덕이 40세대도 함께 볼 수 있습니다.
2. **모두의 단축 거리 합계**를 누릅니다. 광상로 310 동측도로가 1위입니다. 광상로 344에서 도움센터까지 1,463m, 후보까지 369.5m로 추정합니다. 등록 28세대가 한 번씩 배출하면 편도 합계 30.62km가 줄어듭니다.
3. 광상로 344에서 **이 가정 적용**을 누르면 단지 내 배출 조건으로 경로당옆이 1위가 됩니다. **마을 도움센터도 이용 가능** 선택을 풀면 클린하우스 목록만 포함한 경우를 봅니다. ‘다른 배출장 거리 입력’에서 현장에서 확인한 다른 시설까지의 편도 거리도 반영할 수 있습니다.
4. **금능리**를 고르면 가장 많은 세대가 혜택을 보던 후보가 센터 제외 시 71세대, 센터 포함 시 0세대인 이유를 주소별로 확인할 수 있습니다. 봉성리에서도 센터 포함 시 네 후보의 추가 단축 효과가 0입니다.
5. **회의자료 인쇄**로 선택 조건과 두 시나리오, 순위, 주소별 근거를 출력합니다. **근거 CSV 저장**에는 센터 주소, 보행거리, 포함 여부, 적용한 배출장이 함께 기록됩니다. **공개자료 기준으로 초기화**하면 센터 이용 가능 가정으로 돌아갑니다.

문턱을 100m로 설정하면 100m 이상 줄어드는 주소의 세대만 ‘혜택 세대’에 셉니다. 총 단축 거리와 ‘짧아진 세대당 평균’은 거리 문턱과 독립적으로 계산합니다. 기준이 양수인 후보가 없으면 1위가 없습니다.

## Claude 자유 질문

질문 예시로 “유수암리에서 두 기준의 1위가 왜 달라?”, “광상로 344에 자체 수거함이 있다면 전체 거리가 가장 많이 줄어드는 곳은?”, “금능리에서 도움센터 포함 전후에 혜택을 받는 세대 수가 얼마나 달라져?”을 사용할 수 있습니다.

**센터·평가 PC에서 Anthropic API를 사용할 때** 참가자의 평가용 키를 서버 실행 전에 환경변수 `ANTHROPIC_API_KEY`로 설정합니다. Anthropic Console에서 키를 발급하고 평가 중 사용할 모델, 가용 크레딧 및 사용 한도를 확인하세요. 기본 모델은 `claude-haiku-4-5-20251001`이며 `ANTHROPIC_MODEL`로 변경할 수 있습니다. 대회 규정상 평가용 AI 키와 비용은 참가자 부담입니다. 키 발급·외부 전달·한도 설정은 계정 소유자가 관리합니다. 공개 기획서나 화면에 키를 기재하지 마세요. 심사 전용 ZIP에 평가용 키를 별도로 제공하는 경우 규정의 전용 키 예외와 평가 종료 후 폐기 안내를 따릅니다. [Anthropic Console](https://platform.claude.com/) · [대회 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)

Windows PowerShell에서 입력을 숨긴 채 현재 프로세스에 키를 설정하는 예시입니다. 이 명령은 실제 입력한 키를 화면이나 파일에 기록하지 않습니다.

```powershell
$onePlaceSecret = Read-Host "Anthropic evaluation key" -AsSecureString
$env:ANTHROPIC_API_KEY = [System.Net.NetworkCredential]::new('', $onePlaceSecret).Password
$env:ANTHROPIC_MODEL = "claude-haiku-4-5-20251001"
py -3 -X utf8 app.py
```

**로그인된 Claude Code가 설치된 PC**에서는 평가용 키와 API 환경변수가 모두 없으면 Claude Code의 Haiku를 사용합니다. `claude auth status`에서 로그인 상태를 확인하세요. 개발 PC에서 Claude Code 경로와 평가용 키를 이용한 Anthropic Messages API 경로로 각각 실제 자유 질문을 검증했습니다. 외부 인증이나 인터넷 연결이 없을 때는 마을·기준·추가 조건을 화면에서 직접 골라 같은 계산과 인쇄를 사용할 수 있습니다.

질문, 지원 마을·공개 주소·세대 수, 선택된 단지 조건을 모델에 보냅니다. 이름·전화번호 등 개인정보를 질문에 입력하지 마세요. CLI에는 파일 접근 도구를 제공하지 않으며 임시 디렉터리에서 실행합니다. 모델은 마을과 계산 조건을 계획하고 서버가 허용된 값만 검증해 계산합니다. 도구 호출 정의와 프롬프트는 agent.py에 있습니다.

화면 예문 “유수암리에서 두 기준의 1위가 왜 달라?”는 모델이 연결되지 않거나 예문을 잘못 해석해도 같은 두 계산을 실행합니다. 이때 답변 아래에 ‘로컬 예문 해석’을 표시합니다. 예문에서 마을 이름을 바꿀 수 있습니다. 그 밖의 자유 질문에는 Claude 연결이 필요합니다.

## 파일과 검증

| 파일 | 용도 |
|---|---|
| app.py · start.cmd | 로컬 서버와 Windows 실행 |
| agent.py | Claude 질의, 프롬프트, 구조화된 비교 계획, 도구 실행 |
| engine.py | 마을 조회, 후보 비교, 주소별 가정 변화 검사 |
| prepare.py · data/ | 공개 원본과 보행거리표로 분석 자료 재생성 |
| web/ | 화면, 위치도, 인쇄, 근거 CSV |
| verify.py | 원본 지문 확인, 후보 및 현장 가정 회귀 검증 |
| 데이터와_결과.md | 데이터 출처와 이용조건, 분석식, 결과, 검증 한계 |

압축을 푼 폴더에서 `py -3 -X utf8 verify.py`를 실행하면 원본 파일을 확인하고, 저장된 거리표로 자료를 다시 만들어 순위와 480개 조건 조합을 검증합니다. `prepare.py` 기본 동작에는 네트워크나 키가 필요 없습니다. `--refresh`는 FOSSGIS 보행 서비스에 공개 좌표를 보내 거리표를 갱신하므로, 별도 복사본에서 사용하세요. 보행망이 바뀌면 검증용 고정값과 결과가 달라질 수 있습니다.

## 문제 해결

- Python 실행기가 없으면 Python 3.10 이상을 설치한 후 다시 실행합니다. 센터의 설치 권한은 현장 운영 환경에 따릅니다.
- 브라우저는 콘솔에 표시된 **127.0.0.1** 주소로 엽니다. 기본 실행은 사용 가능한 포트를 자동으로 고릅니다.
- Claude 응답에 시간이 걸리거나 서비스 오류가 나면 현재 화면 조건은 유지됩니다. 인터넷, 계정, 키 사용 한도와 모델 접근을 확인하거나 화면에서 조건을 직접 선택합니다.
- 모호한 주소나 지원 범위 밖의 질문은 다시 묻습니다. 자유 질문의 모델 해석에는 변동이 있으므로 결과 카드에 표시된 조건을 함께 확인합니다.
- 지점 운영 여부·단지 자체 수거함·수거차 진입 여부는 현장을 확인합니다. 앱에서 관측한 거리를 넣고 근거 CSV를 보존할 수 있습니다.
