센터 실행판에서 Claude에게 물은 질문

“금능리에서 도움센터 이용 전후에 혜택을 받는 세대 수를 비교해 줘.”

Claude Haiku가 질문에서 마을과 비교 조건을 골랐고, 분석 도구가 두 번 계산했습니다. 센터를 제외했을 때는 제주 만석이펜션 맞은편 도로가 71세대, 센터를 이용할 수 있을 때는 네 후보 모두 0세대입니다.

웹 데모에서는 위 조건을 직접 바꿀 수 있습니다. 자유 질문과 임의 거리 입력은 센터 실행판에서 이용하세요.

표에 있는 세대는 공동주택대장에 등록된 세대입니다. 단독주택, 실제 입주 여부, 자체 수거함, 수거차 진입과 현장 운영 여부를 따로 확인하세요. 편도 거리는 공개 보행망의 추정치입니다.
